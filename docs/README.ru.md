# Letter Dispatcher — LIGHT

Локальная браузерная версия. Откройте `index.html` в корне этого архива — там страница с объяснением установки на русском, английском, французском и испанском (переключатель RU/EN/FR/ES вверху страницы).

## Коротко, что внутри

- `app/index.html` — само приложение (открывается в любом браузере, работает офлайн после первого открытия, можно установить как значок на рабочий стол или на экран телефона — кнопка прямо в приложении).
- `extension-lite/` — лёгкое расширение для Chrome (открывает готовое письмо в Gmail/Outlook в один клик).
- `docs/` — вся документация (этот файл и всё остальное).

## Что LIGHT умеет, а что — нет

Работает полностью локально в браузере на каждом устройстве, без автоматической синхронизации между устройствами или людьми. Единственный способ обмена данными — вручную, через копирование в Google Sheets или Excel (кнопки «Copy for Google Sheets» / «Import from Google Sheets» на вкладке «Контакты» самого приложения). Если нужна настоящая живая синхронизация для команды — см. отдельный архив **SYNC**; если нужны отдельные установочные файлы `.exe`/`.apk` — см. архив **EXE**.
