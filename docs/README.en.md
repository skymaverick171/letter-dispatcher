# Letter Dispatcher — LIGHT

The local, browser-only edition. Open `index.html` at the root of this archive — it explains installation in Russian, English, French, and Spanish (RU/EN/FR/ES switcher at the top of the page).

## What's inside, briefly

- `app/index.html` — the app itself (opens in any browser, works offline after the first open, can be installed as a desktop or phone home-screen icon — a button right inside the app does this).
- `extension-lite/` — a lightweight Chrome extension (opens a ready-to-send Gmail/Outlook draft in one click).
- `docs/` — all documentation (this file and everything else).

## What LIGHT can and can't do

Runs entirely locally in the browser on each device, with no automatic sync between devices or people. The only way to move data around is manual — copy/paste via Google Sheets or Excel (the "Copy for Google Sheets" / "Import from Google Sheets" buttons on the app's Contacts tab). If you need real live sync for a team, see the separate **SYNC** archive; if you need standalone installer files (`.exe`/`.apk`), see the **EXE** archive.
