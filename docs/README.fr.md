# Letter Dispatcher — LIGHT

L'édition locale, tout dans le navigateur. Ouvrez `index.html` à la racine de cette archive — la page explique l'installation en russe, anglais, français et espagnol (sélecteur RU/EN/FR/ES en haut de la page).

## Ce que contient l'archive, en bref

- `app/index.html` — l'application elle-même (s'ouvre dans n'importe quel navigateur, fonctionne hors ligne après la première ouverture, peut être installée comme icône sur le bureau ou l'écran d'accueil du téléphone — un bouton dans l'application le fait directement).
- `extension-lite/` — une extension Chrome légère (ouvre un brouillon Gmail/Outlook prêt à l'emploi en un clic).
- `docs/` — toute la documentation (ce fichier et le reste).

## Ce que LIGHT sait faire, et ce qu'elle ne fait pas

Fonctionne entièrement en local dans le navigateur, sur chaque appareil, sans synchronisation automatique entre appareils ou personnes. Le seul moyen d'échanger des données est manuel — copier-coller via Google Sheets ou Excel (boutons « Copy for Google Sheets » / « Import from Google Sheets » dans l'onglet Contacts de l'application). Si vous avez besoin d'une vraie synchronisation en direct pour une équipe, voir l'archive séparée **SYNC** ; pour des fichiers d'installation autonomes (`.exe`/`.apk`), voir l'archive **EXE**.

## Documents dans ce dossier

- `beta-tester-guide.ru/en/fr/es.html` — comment utiliser l'application (pour la personne à qui vous la remettez).
- `google-sheets-excel-bridge.ru.md` — détails complets sur l'échange avec les tableurs (en russe ; demandez une traduction si besoin).
- `google-sheets-template/` — un modèle de tableau de contacts prêt à l'emploi (.xlsx).
- `google-sheets-template-install.ru/en/fr/es.md` — comment installer (ouvrir) ce modèle dans Google Sheets en particulier, et séparément dans Excel.
- `quick-install.html`, `install.html` — les mêmes étapes d'installation avec captures d'écran, pour la version déjà hébergée en ligne (lien à l'intérieur).
- `extension-lite/README.ru.md` — installation de l'extension Chrome.
