# Как правильно удалить Letter Dispatcher (и почему просто убрать иконку не всегда достаточно)

Когда вы «устанавливаете» Letter Dispatcher, браузер не просто кладёт ярлык на рабочий стол — он регистрирует программу как отдельное приложение (на Android это называется WebAPK, на Windows и Mac — похожий механизм). Если убрать только иконку с экрана или с рабочего стола, для системы приложение может по-прежнему считаться установленным — и тогда при повторной установке появляется сообщение вроде «Программа уже установлена», а кнопка установки перестаёт работать.

Чтобы установить программу заново, нужно удалить её полностью — не иконку, а само приложение. Ниже — как это сделать на каждой системе.

## Android (Chrome)

1. Откройте **Настройки телефона → Приложения** (или «Приложения и уведомления»).
2. Найдите в списке **Letter Dispatcher**.
3. Нажмите **«Удалить»** / **«Uninstall»**.

Быстрый способ найти его без поиска по настройкам: в адресной строке Chrome введите `chrome://apps` — там показаны все установленные веб-приложения, можно удалить прямо оттуда долгим нажатием → «Удалить».

После этого зайдите на сайт заново через Chrome — кнопка установки снова предложит поставить приложение с нуля.

## Windows (Chrome или Edge)

1. В адресной строке введите `chrome://apps` (для Edge — `edge://apps`).
2. Найдите **Letter Dispatcher** → нажмите правой кнопкой мыши → **«Удалить»** (Remove/Uninstall).

Либо через саму Windows: **Параметры → Приложения → Установленные приложения** → найти Letter Dispatcher → **Удалить**.

## macOS (Safari)

Если приложение было добавлено через **Файл → Добавить в Dock**:

1. В Dock (или в папке **Программы**) найдите значок Letter Dispatcher.
2. Перетащите его в Корзину — как обычное приложение.

Если оно было установлено через Chrome/Edge на Mac — тот же способ, что для Windows выше (`chrome://apps`).

## iPhone / iPad

На iOS ярлык «На экран «Домой»» удаляется полностью и без остатка — никакого отдельного шага не требуется:

1. Нажмите и удерживайте иконку на экране «Домой».
2. Выберите **«Удалить приложение»** (Remove App) → **«Удалить»**.

После этого можно сразу же добавить ярлык заново через Safari (Поделиться → «На экран «Домой»»).

## Если ничего не помогает

Иногда браузер «запоминает» установку даже после удаления через `chrome://apps`. В этом случае помогает полный сброс данных сайта:

1. Откройте [https://skymaverick171.github.io/letter-dispatcher/](https://skymaverick171.github.io/letter-dispatcher/) в Chrome.
2. Нажмите на значок замка (или ⓘ) слева от адреса → **«Настройки сайта»**.
3. Выберите **«Сбросить разрешения и удалить данные»** (Reset permissions and clear data).

Либо через `chrome://settings/content/all` — найдите `skymaverick171.github.io` в списке и удалите. После этого статус установки сбрасывается полностью, и кнопка установки снова работает как в первый раз.

**Важно:** сброс данных сайта удалит и все локально сохранённые контакты/письма в этом браузере (они хранятся прямо в нём, без облака) — если что-то важное ещё не перенесено, сначала сделайте **«Copy for Google Sheets»** или **«Download CSV»** на вкладке Contacts, чтобы не потерять данные.
